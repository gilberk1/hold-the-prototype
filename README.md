# Hold the...

A mobile app concept that helps people cook with ingredients they're comfortable with. Master's thesis project for the M.S. in User Experience & Interaction Design at Philadelphia University (2016-2017).


## About

When a recipe includes an ingredient you can't or don't want to eat, Hold the... suggests a few substitutions and lets you choose, so you stay in control while learning how ingredients work together to mimic flavors. It's as much a cooking helper as a recipe helper.

This repo contains the coded, interactive prototype I built and used for user testing.

## My role

UX researcher, designer, and developer.

## Process

- Competitive analysis of SuperCook, MyFitnessPal, and Allrecipes
- Survey of 38 people in the target audience, plus user interviews, personas, and an affinity diagram
- User flows, wireframes, brand identity, UI kit, and mockups
- User testing with a 25-step task script, followed by design changes based on the results

## Built with

HTML, CSS, and JavaScript, plus the Transit, noUiSlider, and Swiped libraries.
